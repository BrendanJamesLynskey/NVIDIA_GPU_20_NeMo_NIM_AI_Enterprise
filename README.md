# NeMo, NIM & AI Enterprise — NVIDIA's Production AI Stack

NVIDIA's full-stack answer to building and serving enterprise AI: NeMo Framework (pretraining + fine-tuning, built on Megatron-LM), NeMo Aligner (RLHF, DPO, PPO), NeMo Curator (data prep), NeMo Guardrails (safety), NIM microservices (one-line model deployment), Base Command (cluster control), Run.ai (K8s scheduling), and the AI Enterprise commercial bundle that ties it together. Includes an interactive stack builder.
